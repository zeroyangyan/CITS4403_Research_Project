For the project demonstration: this is a standalone JavaScript reimplementation of the src/model.py mechanisms from the uploaded CITS4403 project, not a playback of the Python experiment CSV files. It retains four states, degree-based fact-checkers, 5% resistant agents, 1% initial believers, synchronous exposure updates, paired symmetric agent heterogeneity, and the core formulas. Browser network/layout and PRNG implementations differ from Python NetworkX/NumPy, so exact trajectories and quantitative results will not match the submitted Python simulations. Use the report/CSV for the 31,500-run statistical findings. Network average degree is approximately 8, WS rewiring probability 0.10 and correction sharing is enabled. Runs stop when believers disappear or after 300 steps.
